# 四字 · 每日猜成语

每天一个四字成语，十次机会。每猜一次，格子会标出哪些字、哪些声母、韵母和声调对上了。

- **每日一题**：同一天大家猜同一个成语，记录连胜与猜中次数分布
- **自由练习**：常用词库约 1500 个、进阶词库约 3600 个，不限次数
- **成语集**：猜中的成语连同释义、出处、例句、近反义词收进集子里
- 输入框支持拼音首字母联想，如 `hlds` → 画龙点睛
- 深浅色主题、可隐藏拼音提高难度、可复制战绩

记录保存在本机浏览器的 localStorage 中。

## 数据

- 成语、拼音、释义、出处、例句：[mapull/chinese-dictionary](https://github.com/mapull/chinese-dictionary)
- 常用度：[THUOCL 清华大学开放中文词库](https://github.com/thunlp/THUOCL) 成语词频
